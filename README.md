This is a London Underground planner which I made in Python, using mainly libraries such as Dijkstra's and Tkinter.
I made this for my A Level OCR Computer Science NEA project.

When running the Python file, ensure that the 3 CSV files also attached here in the repository are located in the same folder/directory as the Python file

FYI On certain route queries or searches, the Northern line may give the wrong direction to take. Consult a TfL map if necessary, before travelling and using the directions given by this app.
